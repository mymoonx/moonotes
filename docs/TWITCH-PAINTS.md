# Twitch и пейнты Chatterino+ — статус интеграции

> **Экспериментальная ветка.** В публичный релиз 0.5.3 эти изменения пока не входят.

## Что реализовано

- Настройки Moonotes → **Аккаунт** → привязка Twitch.
- Авторизация через официальный Twitch Device Code Flow. Вводить пароль Twitch в Minecraft **не нужно**.
- Подтверждение идентификатора Twitch через официальный эндпоинт \`https://id.twitch.tv/oauth2/validate\`.
- Локальное сохранение **только** публичного Twitch ID, логина и публичного Client ID в \`config/moonotes-twitch-link.json\`.
- Отвязка аккаунта и отмена ожидающей авторизации; не хранятся токены, пароли, client secret.
- Офлайновые проверки корректности ответов Twitch и проверки доверенного домена авторизации.

## Что необходимо для проверки привязки

1. Зарегистрировать публичное приложение в [Twitch Developer Console](https://dev.twitch.tv/console/apps), получить **Client ID**. Не использовать и не публиковать Client Secret.
2. В моде открыть \`/moonotes\` → **Настройки → Аккаунт → Подключить Twitch**.
3. Ввести публичный Client ID, нажать «Подключить Twitch». Должен появиться код.
4. Открыть **twitch.tv/activate**, ввести код и подтвердить вход. Мод проверит результат через официальный API Twitch.
5. После успешного входа в интерфейсе появится логин, а в локальном файле — Twitch ID. При отвязке ID и логин очищаются.

**Ограничение:** привязка пока **локальная и не публично проверяемая**. Это не привязка Minecraft UUID через серверный плагин; она не доказывает третьим лицам, кому принадлежит Minecraft-профиль. Не используйте такую привязку для прав доступа.

## Что пока не готово

**Полное отображение PLUS-пейнтов Chatterino+ в чате, TAB и над персонажами ещё НЕ реализовано.** API-пейлоады, договорённые лимиты и разрешения на стороннее использование необходимо сверить с опубликованным контрактом. Нельзя подменять проверку стороннего API угадыванием недокументированных URL. В текущей ветке нет запросов к \`chat.eblo.id\` и никакие пейнты не скачиваются.

Интеграцию нужно продолжить после подтверждения официальных endpoint-ов и формата градиентов/изображений; с отдельными ограничениями частоты, кешем, анимациями и индивидуальными настройками чата/TAB/имён над игроками. На **Paper** пользовательская визуализация по-прежнему требует установленного клиентского Moonotes. Server Bridge для чужих подтверждённых привязок пока отсутствует.

## Безопасность и приватность

- Device Code открывается пользователем на официальном Twitch; OAuth-токен используется только в памяти и выбрасывается после \`validate\`.
- Необходимых OAuth scopes нет: мод не запрашивает права чата, чтения почты или модерации.
- Настройки сохраняются локально, автоматически никуда не отправляются.
- Публичный Client ID не является секретом. Client Secret никогда не вводится в мод и не включается в JAR.
- Любые будущие интеграции связывания Minecraft UUID ↔ Twitch ID требуют отдельного механизма подтверждения и согласия.
