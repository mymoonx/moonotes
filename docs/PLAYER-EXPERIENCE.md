# Moonotes Network 0.6.0-beta.1 — удобство и поддержка

**Статус:** тестовая версия на базе проверенной 0.6.0-alpha.4. **Не публиковать как Latest до повторного тестирования в Minecraft 26.3.**

## Установка

Minecraft Java 26.3, Fabric Loader 0.20.1+, совместимый Fabric API, Java 25, оригинальный Streamotes 1.2.16+26.3, основной `moonotes-0.4.1.jar` и **ровно один** `moonotes-network-0.6.0-beta.1.jar` в папке `mods`.

Все файлы `config/moonotes-*.json`, группы, избранное и кеш сохраняются. Старое `moonotes-wheel.json` с восемью слотами автоматически читается как первая страница. Отдельной команды миграции не требуется.

## Управление

- В Minecraft → **Настройки → Управление → Moonotes**: бинд колеса (`G`), бинд менеджера Moonotes (изначально не назначен), бинд мини-библиотеки (изначально не назначен). Встроенный чат не меняет штатные клавиши.
- В `/moonotes → Настройки → Дополнительно → Кнопки и префикс чата`: перетащите по отдельности кнопки «Эмоты» и «⚙ Moonotes». Положения привязаны к границам окна и сохраняются отдельно от HUD. Кнопки нельзя сохранить в пересекающемся положении.
- Здесь же задайте **публичный текстовый префикс глобального чата текущего сервера**: `!`, `#`, `@`, `~` и т. п., 1–4 символа. Команды через `/g` не считаются префиксом текста и пока не поддерживаются этим полем. Префикс не отправляется автоматически без нажатия ЛКМ в колесе.
- При смене сервера настройки префикса и выбранной страницы колеса восстанавливаются по **SHA-256 ключу адреса**. Сам адрес сервера в файле настроек колеса не сохраняется.

## Многостраничное колесо

- В игре `G` → стрелки сверху или прокрутка над кольцом переключают страницы.
- `Настроить`: появятся кнопки предыдущей/следующей страницы, **+ Страница**, **Удалить**, **Группа →**, **Отвязать** и поле для имени страницы. Максимум 20 страниц.
- Ручная страница содержит восемь своих эмотов и сохраняется отдельно.
- Страница **из группы** читает состав из тех же групп, которыми пользуется мини-библиотека. Группа с 12 эмотами может быть представлена двумя связанными страницами (первые 8 и следующие 4).
- Создание/удаление, связь группы, смена названия сохраняются **сразу**. Изменение восьми ручных слотов сохраняется кнопкой «Сохранить»; перед сменой страницы нужно его сохранить.
- При переименовании группы в мини-библиотеке связанную страницу может потребоваться перепривязать — текущие группы имеют имена как ключи, не отдельные постоянные ID.

## Диагностика и производительность

В `Настройки → Дополнительно → Диагностика и поддержка` доступны:

- **Самодиагностика:** версии, наличие Fabric API/Streamotes, доступность папки настроек, количество каталогов/групп, состояние настроек и категории неполадок.
- **Копировать отчёт:** только сформированные технические поля. `latest.log` и crash report **автоматически не включаются**. Лог может содержать личные данные: пользователь прикладывает его сам после проверки.
- **Сообщить об ошибке:** копирует отчёт и по прямому нажатию открывает [GitHub Issues](https://github.com/mymoonx/moonotes/issues/new?template=bug_report.yml) в браузере. Нужна явная публикация пользователем: это **не автоматическая отправка** и GitHub-обращение не является анонимным.
- **Резервная копия:** создаёт ZIP строго из настроек Moonotes в `config/moonotes-backups`. Не копирует кеш изображений, токены, логи, данные других модов. «Восстановить» требует повторного нажатия и перезапуска Minecraft; перед заменой создаётся страховочная копия.
- **Режим качества:** экономичный (до 3 анимаций и 32 кадров), сбалансированный (до 8 анимаций и 128 кадров), высокий (до 12 анимаций и 256 кадров). Ограничивает бюджет отрисовки эмотов в книгах, табличках и реакциях. На корректность групп, чата и сохранённых изображений не влияет.
- **Проверка обновлений:** выполняется вручную через официальный API GitHub Releases. Никаких автоустановок JAR.
- **Добровольная агрегированная телеметрия:** по умолчанию выключена. При включении считаются лишь фиксированные категории действий текущей сессии без содержимого чата, никнеймов, адресов серверов и идентификаторов эмотов. Счётчики можно включить в ручной отчёт. **Сетевой получатель телеметрии пока не развёрнут, автоматическая передача отключена даже при opt-in.** Выключение очищает счётчики.

## Безопасность

Все изменения клиентские. Никакой новый серверный плагин или Twitch OAuth не требуется. Cloudflare Worker, предоставляющий общие 7TV-файлы, не получил endpoint для личных данных. Передача диагностических логов или агрегатов не запускается в фоне.

## Игровой чек

1. Перезапустите игру со старым `moonotes-wheel.json`: первая страница должна содержать прежние восемь эмотов.
2. Создайте вторую страницу, назначьте эмот, переключите страницы и перезапустите игру.
3. Свяжите страницу с группой мини-библиотеки, добавьте эмот в группу и повторно откройте колесо; проверьте обновление. Для групп больше 8 попробуйте вторую страницу.
4. Поменяйте глобальный префикс, отправьте эмот ЛКМ и проверьте, что на другом сервере остаётся другое значение.
5. Перетащите кнопки чата. Проверьте изменение GUI Scale и возвращение кнопок после перезапуска.
6. Назначьте отдельные клавиши меню и мини-библиотеки в стандартном управлении Minecraft.
7. Сделайте резервную копию и восстановите её с подтверждением; перезапустите игру.
8. Запустите самодиагностику, скопируйте отчёт, убедитесь в отсутствии никнеймов, URL сервера, токенов и текста чата.
9. Сравните FPS в экономичном и высоком профилях рядом с несколькими анимированными табличками.
