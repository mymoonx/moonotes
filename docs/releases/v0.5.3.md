# Moonotes 0.5.3 — каталоги, группы и уведомления

Клиентские дополнения для **Minecraft Java 26.3 / Fabric / Java 25**.

Состав релиза:

- **Moonotes Network 0.5.3** — библиотека, каталоги, загрузка, мини-библиотека и HUD.
- **Moonotes 0.4.1** — предпросмотр ввода и каналы текущего мира.
- **Cloudflare Worker 0.5.3** — резервная загрузка через R2.

Оригинальный **Streamotes 1.2.16+26.3** устанавливается отдельно.

## Изменения

- Исправлена загрузка новых изображений: мод и Worker сразу используют канонические адреса CDN 7TV, включая старые ID.
- Общий кеш и существующие объекты R2 используются повторно.
- Настройки получили боковую навигацию; поля ввода оформлены в цвет интерфейса.
- Кнопки возле чата подписаны «Эмоты» и «Moonotes».
- Создание и переименование групп отделены от поиска; состав группы выбирается явно.
- Звезда и меню эмота имеют раздельную подсветку и подсказки.
- Автоматические уведомления Streamotes могут показываться в общей очереди с Moonotes.

## Установка

Закрой Minecraft и помести JAR Moonotes и Network в `mods`, оставив по одной версии каждого. Для обновления с предыдущего комплекта достаточно заменить Network; основной Moonotes 0.4.1 подходит. Каталоги, группы, избранное и кеш сохраняются.

Владельцу резервного сервиса нужно обновить Worker до 0.5.3 через `01-DEPLOY.cmd`, затем проверить `/health`. Обычному игроку разворачивать собственный Worker не требуется.

## Проверка

Пройдены 29 программ проверок Network, 30 тестов Worker и проверки совместимости Streamotes. Проблемный эмот реально скачан клиентом и функцией нового Worker. Автор проекта подтвердил работу версии в игре.

Готовые JAR этой первой публикации собраны Java 25 против настоящих библиотек игры; подробности и ограничения проверки находятся в `docs/VERIFICATION.md`. Результаты GitHub Actions следует смотреть отдельно по фактическому запуску.
