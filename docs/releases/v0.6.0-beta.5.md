# 🌙 Moonotes 0.6.0-beta.5 — более удобное колесо эмотов

**Minecraft Java 26.3 · Fabric Loader 0.20.1+ · Fabric API · Java 25**

Предварительная версия Moonotes на основе beta.4, включающая исправления интерфейса и все возможности предыдущих alpha/beta. Автор подтвердил, что новая сборка запускается и работает в игре; версия остаётся тестовой.

> **Важно:** оставьте оригинальный Streamotes 1.2.16+26.3. Для работы нужны **оба JAR Moonotes** из Assets ниже.

## ✨ Что нового в beta.5

- **Чистый центр колеса:** название страницы больше не дублируется. Без наведения на эмот отображаются название страницы и счётчик `1/2`, а при наведении — имя эмота с контекстом страницы. На единственной странице лишний счётчик скрывается.
- **Анимированный предпросмотр в редакторе:** наведите курсор на эмот примерно на полсекунды — появится крупная карточка с изображением, названием и каналом. Анимация использует уже существующие кадры кеша Streamotes, а список остаётся лёгким и статичным.
- **Аккуратная кнопка настроек:** текстовая шестерёнка удалена; верхняя панель компактнее.
- **Корректное расположение:** всплывающий предпросмотр старается появляться сбоку и не перекрывает нижние кнопки «Сохранить» и «Отмена».
- **Ресурсы и стабильность:** только один увеличенный предпросмотр за раз; при смене эмота его временные текстуры освобождаются. Добавлены проверки текста и расположения для нескольких размеров GUI.

## 🎮 Возможности из предыдущих beta

- Колесо с **несколькими страницами**, восемью слотами на страницу и привязкой страниц к группам из мини-библиотеки.
- Клавиша **G**: ЛКМ отправляет эмот, Shift + ЛКМ открывает черновик, ПКМ показывает локальную реакцию; выбор локального и глобального чата.
- Обновлённый редактор слотов со списком, поиском и контекстным меню `⋯`; адаптивная мини-библиотека.
- Эмоты на табличках, в книгах и на кафедрах. При корректных метаданных кеша поддерживается анимация; исходный текст сохраняется.
- Локальные реакции возле игроков, подсказки ввода, библиотека 7TV, каталоги, избранное, группы и общий кеш Streamotes.
- Раздел поддержки, резервные копии и **настройки проверки обновлений** с безопасной проверкой контрольных сумм перед установкой и возможностью отката.

Картинки в самом колесе и реакции могут оставаться статичными. Анимация предпросмотра доступна отдельно, при наведении в редакторе; недостающие или неподдерживаемые анимации отображаются статично.

## 📦 Установка и обновление

1. Закройте Minecraft 26.3.
2. Сохраните совместимые Fabric API и оригинальный Streamotes в папке `mods`.
3. Уберите старую версию `moonotes-network-*.jar` (оставлять две одновременно нельзя).
4. Установите из Assets:
   - **`moonotes-0.4.1.jar`** — основной компонент (не изменился).
   - **`moonotes-network-0.6.0-beta.5.jar`** — обновлённый компонент с библиотекой и колесом.
5. Запустите Minecraft и откройте `/moonotes`; колесо открывается клавишей **G**.

Сохранённые группы, настройки и кеш рассчитаны на сохранение при обновлении. Worker отдельно устанавливать не требуется.
