# 🌙 Moonotes 0.6.0 — стабильный выпуск

**Minecraft Java 26.3 · Fabric Loader 0.20.1+ · совместимый Fabric API · Java 25**

Moonotes — клиентский менеджер эмотов 7TV для Minecraft с каталогами Twitch-каналов, быстрым выбором смайликов, колесом, мини-библиотекой и визуализацией эмотов в мире. Выпуск основан на проверенной пользователем 0.6.0-rc.1 и на предыдущих beta-сборках.

> **Обязательно оставьте оригинальный Streamotes!** Moonotes работает рядом с ним, а не вместо него. Для полного комплекта установите два JAR Moonotes из Assets этого релиза.

## ✨ Возможности версии 0.6.0

- **Библиотека 7TV:** подключение Twitch-каналов и наборов, поиск, фильтры, избранное, недавние эмоты и собственные группы.
- **Удобный чат:** компактная мини-библиотека и подсказки при вводе. **Tab / Shift+Tab** выбирают эмот; **стрелки по умолчанию не перехватываются**, их можно отдельно включить в `/moonotes → Настройки → Чат`.
- **Колесо эмотов (G):** до восьми эмотов на странице, несколько страниц, связь с группами, удобный редактор, увеличенный анимированный предпросмотр при наведении. ЛКМ отправляет эмот, Shift+ЛКМ готовит черновик, ПКМ запускает собственную реакцию.
- **Реакции:** от третьего лица эмот виден над собственным персонажем, от первого — в небольшой панели. Повторное ПКМ обновляет реакцию сразу. Если изображение ещё не готово, появляется заглушка.
- **Книги и таблички:** эмоты рисуются как изображения в мире и в интерфейсах книг; анимация доступна, когда в кеше Streamotes есть подходящие кадры и тайминги.
- **Настройки и надёжность:** улучшены компоновка и расположение кнопок, диагностика, резервные копии, режимы производительности и проверка обновлений через GitHub Releases с контрольными суммами SHA-256.

### ⚠️ Важно о мультиплеере и реакциях

**Реакции по ПКМ работают только на вашем клиенте.** Другие игроки **не увидят их автоматически** — даже если тоже установят Moonotes 0.6.0. Эта версия не содержит синхронизации реакции по сети. На своём клиенте можно увидеть реакцию другого игрока по распознанному сообщению с эмотом в чате, но это зависит от формата сообщений и не работает со всеми серверными плагинами. Для настоящей общей системы реакций понадобится отдельное обновление.

## 📦 Установка

**Требуются:** Minecraft Java **26.3**, Java **25**, Fabric Loader **0.20.1+**, совместимый Fabric API и [оригинальный Streamotes 1.2.16+26.3 (Fabric)](https://www.curseforge.com/minecraft/mc-mods/streamotes/files/9032701).

1. Полностью закройте игру.
2. Оставьте в `mods` оригинальный Streamotes и Fabric API.
3. Удалите **предыдущий** `moonotes-network-*.jar`. Одновременно две версии Network ставить нельзя.
4. Установите из раздела **Assets** этого релиза:
   - `moonotes-0.4.1.jar` — основной компонент;
   - `moonotes-network-0.6.0.jar` — библиотека, колесо и функции Moonotes Network.
5. Запустите игру. Откройте настройки через `/moonotes`, колесо — через **G**.

Если два JAR Moonotes уже были установлены, обычно достаточно заменить **Network**. Пользовательские группы, каталоги, настройки и кеш рассчитаны на сохранение. Не удаляйте папку настроек без резервной копии. Cloudflare Worker отдельно устанавливать не нужно.

### Безопасность файлов

В Assets присутствует `SHA256SUMS.txt` с SHA-256 обоих собранных JAR. Это позволяет проверить скачанный файл и используется системой обновлений. Поддерживается установка новой версии после выхода из Minecraft с резервной копией старого Network JAR; сам работающий мод не заменяется во время игры.
