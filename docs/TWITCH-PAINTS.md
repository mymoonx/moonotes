# Moonotes — Twitch-привязка и система пейнтов (эксперимент)

> Это **тестовая ветка**. Публичный релиз **v0.5.3** не изменяется.

## Что сейчас работает в коде

- **Подтверждённая локальная привязка Twitch** через официальный Device Code Flow: сохраняются Twitch ID, логин, публичный Client ID и UUID Minecraft-профиля, **без OAuth-токенов, паролей и Client Secret**.
- **Пейнты включаются только вручную**. Настройки **/moonotes → Настройки → Пейнты**: общий переключатель, чат, TAB, анимация, тестовый градиент и импорт локального JSON.
- **Предпросмотр** градиента прямо в настройках.
- **Тестовый градиент Moonotes**, явно обозначенный как демонстрационный — это **не** настоящий Twitch/PLUS-пейнт.
- **Цветовые градиенты** рисуются по символам в собственном имени игрока в TAB. Цвет в обычном локальном сообщении вида `<MinecraftНик> сообщение` применяется при получении, **без живой анимации чата**. Сложные чат-компоненты, сообщения других игроков, наименования над головами, визуальные пейнты с изображениями и многоуровневые эффекты **пока не поддерживаются**.
- Импорт цветовых данных из `config/moonotes-paint.json`. Данные ограничены по размеру (64 КиБ), числу остановок градиента (32) и числу символов. Никакие сторонние URL из импортированного описания не скачиваются.

## Быстрая проверка

1. Сделайте резервную копию сборки, закройте игру и установите экспериментальную версию **Moonotes Network** вместо старого `moonotes-network-0.5.3.jar`. Оригинальные **Streamotes** и **Moonotes 0.4.1** оставьте.
2. Убедитесь, что привязка Twitch показывает корректный логин в **Настройки → Аккаунт**.
3. Откройте **Настройки → Пейнты**, включите отображение и **тестовый градиент**. В заголовке настроек будет цветной предпросмотр, а собственное имя в TAB должно получить градиент.
4. Отключите демо. До подключения официального PLUS API реальный PLUS-пейнт в Moonotes автоматически не появится.
5. Для ручной проверки можно положить в `config/moonotes-paint.json` пример ниже и нажать «Обновить JSON». Такой ручной пейнт **не доказывает право владения внешним пейнтом**:

```json
{
  "name": "Локальный пример",
  "gradients": [{
    "function": "LINEAR_GRADIENT",
    "stops": [
      { "at": 0, "color": "#60C8FF" },
      { "at": 0.5, "color": "#CC84FF" },
      { "at": 1, "color": "#FFD36C" }
    ]
  }]
}
```

## Что требуется для Chatterino+ PLUS

**Целевой источник — только Chatterino+ PLUS, не 7TV.** Публичный формат и разрешённый механизм подключения **пейнтов Chatterino+ PLUS** пока не были подтверждены через доступную официальную документацию. У Chatterino+ есть ограничения на неофициальные клиенты и автоматические запросы. Мы **не используем недокументированные пути, чужие токены или обход условий сервиса**.

Значит: **реальные PLUS-пейнты из chat.eblo.id пока не скачиваются**. Ранее добавленный загрузчик пейнтов 7TV исключён из экспериментальной ветки как не относящийся к цели проекта. Добавить официально разрешённый адаптер можно после подтверждения условий доступа и формата ответа; нынешняя модель пейнтов уже отделена от сетевого источника.

## Технические ограничения и безопасность

- Все эффекты обрабатываются клиентом. **Сервер Minecraft не изменяется**.
- На сервере без Moonotes Bridge чужие привязки Twitch неизвестны. Пейнт отображается только для **локального** привязанного Minecraft UUID. Привязка не даёт прав на сервере.
- Настройки, импорт и кеш остаются в локальной папке `config`. При смене Twitch ID загруженный с 7TV пейнт другого аккаунта не должен применяться к новому профилю.
- Нет сбора сообщений, логинов других игроков, автоматических сетевых опросов или передачи OAuth-токена другим сервисам.
- Для графики с изображениями, сложных CSS-эффектов, анимации в истории чата, имён над головами и поддержки всех источников потребуются отдельная отрисовка и тестирование в игре.
