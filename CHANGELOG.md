# История изменений

## 0.5.3 — 2026-11-23

Состав: Moonotes Network **0.5.3**, Cloudflare Worker **0.5.3**, основной Moonotes **0.4.1**.

### Исправления

- Прямой клиент и Worker используют канонические адреса CDN 7TV для новых ULID и старых ObjectId. Перенаправление 308 больше не превращается в 502 при загрузке новых изображений.
- Ключи R2 и имена файлов общего кеша сохраняются.
- В диагностике различаются известные ошибки CDN, соединения Worker и кеша R2.
- Поиск и имя группы используют отдельные поля. Отмена переименования сохраняет поисковый запрос.
- Звезда и меню эмота имеют отдельные области наведения; промежуток между ними не вставляет эмот.

### Интерфейс

- Категории настроек вынесены в боковую панель, отличающуюся от главных вкладок.
- Место под ползунок настроек выделяется только при наличии прокрутки.
- Поля ввода оформлены в цвет интерфейса; штатные ввод, выделение и IME сохранены.
- Кнопки возле чата подписаны «Эмоты» и «Moonotes».
- Создание группы: название → выбор эмотов → «Готово». Состав существующей группы меняется кнопкой «+ Эмоты».
- Подсказка вставки уточнена: «Вставить в чат · без отправки».

### Совместимость

- Автоматические уведомления Streamotes могут идти в общей очереди Moonotes. Исходный режим None соблюдается; переключатель «Отдельно» возвращает обычный вывод Streamotes.
- Оригинальный Streamotes остаётся отдельным модом.

### Обновление

Замени Network и обнови Worker через `worker/01-DEPLOY.cmd`. Основной Moonotes 0.4.1 подходит. Существующие конфиги, каталоги, группы и кеш сохраняются.
