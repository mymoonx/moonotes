# Moonotes 0.6.0-rc.1 — управление чатом и реакции

**Основа:** 0.6.0-beta.5 · Minecraft Java 26.3 · Fabric Loader 0.20.1+ · Java 25 · Streamotes 1.2.16+26.3.

Это релиз-кандидат для игрового тестирования, **не стабильный релиз**. Изменения основной версии 0.5.3 не затрагиваются.

## Что изменено

### Подсказки эмотов и стрелки

- По умолчанию **стрелки ↑ ↓ ← → не используются для выбора подсказок**, поэтому Minecraft может обрабатывать курсор и историю чата стандартным способом.
- **Tab / Shift+Tab** продолжают переключать варианты. Пробел вставляет эмот только после явного выбора.
- Настройка: `/moonotes → Настройки → Чат → Выбор эмотов стрелками`. Изначально **Выключено**; включение вручную возвращает старое поведение.
- Любая стрелка при выключенной функции сбрасывает старое выделение, чтобы следующий пробел не вставил случайный эмот. Сохраняется в локальном конфиге.

### Реакции: исправлена обратная связь

- При ПКМ по эмоту в колесе повторная локальная реакция **сразу обновляется**, не упираясь в антиспам-защиту для входящего чата.
- Если реакция не может быть активирована, колесо не исчезает без объяснения, а сообщает об ошибке.
- В первом лице показ собственной реакции усилен: панель с именем эмота и местом для изображения. Пока декодируется картинка или её нет в кеше, отображается узнаваемая заглушка.
- Для других персонажей рендер также показывает заглушку при отсутствии изображения, но по-прежнему учитывает расстояние, невидимость и препятствия.
- Входящие реакции, распознанные из сообщений других игроков, сохраняют антиспам-ограничение.

**Ограничение мультиплеера:** ПКМ запускает реакцию **только на текущем клиенте**. Она не передаётся автоматически другим игрокам. Клиенты с Moonotes могут показывать собственные реакции над отправителем при получении обычного распознанного сообщения с эмотом; серверные/плагиновые форматы чата распознаются не всегда. Для полноценной передачи реакций между клиентами потребуется отдельно реализовать сетевой протокол либо серверную поддержку. Не обещаем поддержку всем игрокам без мода.

## Проверка перед стабильной 0.6.0

1. Ввести название эмота в обычном чате. Убедиться, что **←/→** двигают курсор, **↑/↓** не переключают эмоты, **Tab** переключает подсказки, пробел после выбранного эмота вставляет название.
2. Открыть `/moonotes → Настройки → Чат` и вручную включить стрелки; проверить старое переключение, затем выключить и перезапустить Minecraft: значение должно сохраниться.
3. Включить реакции в `Настройки → Эмоты+`. В первом лице нажать G → ПКМ по эмоту: должна появиться панель реакции слева сверху, а не только закрыться колесо.
4. Повторить ПКМ быстро с другим эмотом: в панели должна появиться новая реакция.
5. Переключиться в F5 и проверить отображение над персонажем на открытом месте, затем за стеной и с расстояния. Проверьте маленькие и обычные размеры GUI.
6. При временно отсутствующей картинке должна появиться заглушка, не зависание или вылет.
7. Проверить игру после закрытия колеса: движение камеры, чат, остальные горячие клавиши, библиотека и колесо должны работать как в beta.5.
8. Отдельно проверить сообщения других игроков и показать **пример настоящей строки чата** с сервера, если над отправителем реакция не отображается.

Автоматические проверки подтверждают компиляцию, настройку клавиш, проекцию и политику повторов. Поведение реакции в клиенте необходимо проверять вручную.
