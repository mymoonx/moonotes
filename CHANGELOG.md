# История изменений

## 0.6.0 — 2026-11-25

Состав: основной Moonotes **0.4.1** (без изменений исходных функций), Moonotes Network **0.6.0**, резервный Cloudflare Worker **0.5.3**.

### Новые возможности
- Колесо с несколькими страницами и группами; восемь эмотов на страницу, выбор канала отправки и редактор слотов.
- Поддержка эмотов в книгах, на кафедрах и табличках; при наличии данных кадров — анимация.
- Крупный анимированный предпросмотр в редакторе; оптимизированы текст, управление, прокрутка и мини-библиотека.
- Локальные реакции по ПКМ: над собственным персонажем (в первом лице — панель), реакция по чату на клиентах, которые могут распознать отправителя и эмот.
- Новые локальные настройки, диагностика, резервные копии, проверка обновлений из GitHub Releases с SHA-256, отложенной установкой и откатом.

### Изменения управления и исправления
- Tab / Shift+Tab выбирают эмот; стрелки ↑ ↓ ← → по умолчанию **не перехватывают** редактирование чата. Старое управление включается отдельным переключателем.
- Убрано повторение заголовка страницы в центре колеса.
- Добавлена обратная связь при нажатии ПКМ: повторная собственная реакция обновляется сразу, при отсутствии картинки показана заглушка.
- Сохранены проверки входа в мир и SDL-клавиш, чтобы неназначенные клавиши не ломали управление камерой.

### Ограничение
- **ПКМ-реакции только локальные:** они не передаются другим игрокам автоматически, даже если установлен Moonotes. Это запланированная граница текущей реализации, а не поддержка мультиплеерной синхронизации.
- Декорация чата серверными плагинами может ограничивать привязку реакций к отправителю.

### Установка
Нужны Minecraft Java 26.3 / Fabric / Java 25, оригинальный Streamotes 1.2.16+26.3, Fabric API и оба JAR Moonotes из релиза. Удалите прежний `moonotes-network-*.jar` перед установкой 0.6.0; группы, кеш и настройки рассчитаны на сохранение.


## 0.5.3 — 2026-11-23

Состав: Moonotes Network **0.5.3**, Cloudflare Worker **0.5.3**, основной Moonotes **0.4.1**.

### Исправления

- Прямой клиент и Worker используют канонические адреса CDN 7TV для новых ULID и старых ObjectId. Перенаправление 308 больше не превращается в 502 при загрузке новых изображений.
- Ключи R2 и имена файлов общего кеша сохраняются.
- В диагностике различаются известные ошибки CDN, соединения Worker и кеша R2.
- Поиск и имя группы используют отдельные поля. Отмена переименования сохраняет поисковый запрос.
- Звезда и меню эмота имеют отдельные области наведения; промежуток между ними не вставляет эмот.

### Интерфейс

- Категории настроек вынесены в боковую панель, отличающуюся от главных вкладок.
- Место под ползунок настроек выделяется только при наличии прокрутки.
- Поля ввода оформлены в цвет интерфейса; штатные ввод, выделение и IME сохранены.
- Кнопки возле чата подписаны «Эмоты» и «Moonotes».
- Создание группы: название → выбор эмотов → «Готово». Состав существующей группы меняется кнопкой «+ Эмоты».
- Подсказка вставки уточнена: «Вставить в чат · без отправки».

### Совместимость

- Автоматические уведомления Streamotes могут идти в общей очереди Moonotes. Исходный режим None соблюдается; переключатель «Отдельно» возвращает обычный вывод Streamotes.
- Оригинальный Streamotes остаётся отдельным модом.

### Обновление

Замени Network и обнови Worker через `worker/01-DEPLOY.cmd`. Основной Moonotes 0.4.1 подходит. Существующие конфиги, каталоги, группы и кеш сохраняются.
