# Moonotes Network 0.6.0

**Релиз:** [Moonotes 0.6.0](https://github.com/mymoonx/moonotes/releases/tag/v0.6.0). Подсказки эмотов управляются Tab/Shift+Tab; стрелки по умолчанию остаются штатными клавишами чата. Реакции по ПКМ являются локальным эффектом, который автоматически не видят другие игроки.

Патч для Minecraft Java **26.3**, Java **25**, Fabric Loader **0.20.1** и Fabric API **0.165.0+26.3**.

В этом обновлении меняется **Moonotes Network**. Основной Moonotes **0.4.1** и оригинальный Streamotes **1.2.16+26.3** остаются отдельными установленными модами. Их повторная установка не требуется. Оригинальный Streamotes в архивы не включён.

## Установка

1. Закрой Minecraft.
2. Убери прежний `moonotes-network-0.5.2.jar` из папки `mods`, сохранив его вне этой папки для отката.
3. Перенеси `moonotes-network-0.6.0.jar` из Releases в `mods` сборки. Должна остаться одна версия Network.
4. Обнови свой Cloudflare Worker по инструкции ниже. Для сетей с недоступным 7TV это необходимая часть исправления.
5. Запусти Minecraft и открой `/moonotes`.

Существующие каталоги, группы, избранное, настройки и изображения читаются на прежних местах. Кеш `emoticons/cache/images` и файлы `config/moonotes*.json` сохраняются; удалять их для обновления не нужно.

## Почему второй каталог добавлялся, но изображения не скачивались

Причина воспроизведена на эмоте **TEATIMEMEGAZOOMAAAAAA** со скриншота. Для ID `01f5z4b9700008kdxa2tjqbngw` CDN 7TV отвечает **HTTP 308** и предлагает тот же ID заглавными буквами. Запрос канонического `01F5Z4B9700008KDXA2TJQBNGW` сразу возвращает **HTTP 200** и WebP размером **30 588 байт**.

В версии 0.5.2 Worker использовал строчные буквы и запрещал перенаправления. Перенаправление CDN становилось ошибкой **502**. Уже сохранённые объекты R2 читались без такого запроса, поэтому общий кеш работал, а новые изображения второго каталога массово не загружались. У клиента на скриншоте отдельно видна ошибка TLS прямого подключения; исправление резервного пути необходимо именно для этого случая.

Начиная с 0.5.3 и мод, и Worker сразу формируют канонический адрес CDN. Старые 24-символьные ID тоже преобразуются по алгоритму SevenTV. Имена файлов локального кеша и ключи R2 остаются прежними. Проверка TLS, запрет произвольных перенаправлений, ограничения размера и проверка изображений сохранены.

Если источник всё же недоступен, диагностика различает известные ошибки получения картинки от 7TV и обращения к R2. Произвольное содержимое серверных ответов не выводится в интерфейс.

## Обновление Worker

1. Полностью распакуй **Moonotes-Worker-0.5.3-SOURCE.zip**.
2. В папке Worker запусти **`01-DEPLOY.cmd`**. Он устанавливает зависимости по lock-файлу, запускает проверки и обновляет Worker. Нужен Node.js 22.12 или новее; при необходимости Wrangler предложит вход в твой аккаунт Cloudflare.
3. Открой `https://moonotes-emotes.thefreelom.workers.dev/health` и проверь:
   - `version`: `0.5.3`;
   - `bucketBound`: `true`;
   - в `capabilities` есть `canonical-cdn-ids`.
4. В Minecraft выбери нужный каталог и нажми **«Загрузка → Добрать отсутствующие»**. Можно оставить источник **Авто**, чтобы при недоступном прямом 7TV использовался Cloudflare.

Имя Worker, привязка `EMOTES`, бакет и существующие ключи R2 сохранены. Запуск `02-PREFETCH-ALL.cmd` для этого обновления не требуется. Создавать новый бакет или повторять полную синхронизацию не нужно.

Архив сам не публикует Worker. Развёртывание происходит после запуска `01-DEPLOY.cmd` владельцем аккаунта. Доступность из каждой пользовательской сети зависит от соединения; обновление не отключает проверку защищённого соединения.

## Что изменилось в интерфейсе

### Настройки

Основные вкладки остаются сверху: «Библиотека», «Каталоги», «Загрузка», «Настройки». Категории настроек **«Чат», «Сеть», «Вид», «Система»** вынесены в боковую панель с отдельным оформлением и отметкой выбранного раздела. Они не выглядят как ещё одна строка главного меню.

Область настроек использует доступную ширину. Место под правый ползунок выделяется только при наличии прокрутки. На узком окне настройки выстраиваются в одну колонку. Поля поиска, канала и названия группы получили фон в цвет панелей и светлую рамку фокуса; ввод, выделение, копирование и IME остаются штатными.

### Кнопки у чата

Вместо значков теперь подписи **«Эмоты»** и **«Moonotes»**. Первая открывает мини-библиотеку, вторая — полный менеджер. Область автоподбора учитывает ширину этих кнопок. При возврате из менеджера сохраняются введённый текст, курсор и выделение.

Управление автоподбором сохраняется: Tab/стрелки выбирают вариант, пробел вставляет его только после начала выбора. Пока выбора нет, пробел остаётся обычным пробелом. Команды с `/` используют обычное автодополнение.

### Группы в мини-библиотеке

**Создание:** «Эмоты → Группы → + Создать группу» → отдельное поле **«Название группы»** → «Создать» → отметить эмоты → «Готово».

В уже созданной группе кнопка **«+ Эмоты»** открывает изменение состава. Один эмот может входить в несколько групп. Меню `⋯` в списке групп позволяет изменить название или удалить группу; удаление группы не удаляет изображения и избранное.

Поиск и имя группы теперь имеют разные поля и состояния. Отмена переименования сохраняет предыдущий поисковый запрос. Поиск, Enter в форме группы и кнопки управления не отправляют сообщение в чат.

Звезда и `⋯` у эмота имеют отдельные области наведения и небольшой промежуток. Нажатие в промежутке не вставляет эмот. Подсказка основной строки: **«Вставить в чат · без отправки»**. Она описывает именно добавление названия в строку ввода; отправка остаётся на Enter в самом чате.

### Общие уведомления со Streamotes

Новая настройка **«Настройки → Вид → Уведомления Streamotes»** по умолчанию установлена в **«В общей очереди»**. Автоматические сообщения Streamotes и Moonotes показываются последовательно в одной области, рядом с прогрессом загрузки. В журнале и чат-режиме сохраняется источник **Streamotes**. Завершение обновления Streamotes описано как количество **названий**, чтобы не путать регистрацию со скачанными изображениями.

Общий способ показа выбирается соседней настройкой **«Уведомления»**: на экране, только ошибки, в чате или выключены. Если сообщения отключены в настройках самого Streamotes (**None**), они остаются отключёнными. Режим **«Отдельно»** возвращает штатные уведомления Streamotes.

Совместимость затрагивает только автоматические сообщения Streamotes. Ответы на команды и уведомления других модов не перенаправляются. Оригинальный JAR Streamotes не изменяется. Журнал событий ограничен и хранится локально в течение сеанса; автоматической отправки диагностики нет.

## Сборка из исходников

Открой PowerShell в папке **network** этого репозитория, где находятся `build.gradle` и `gradlew.bat`:

```powershell
.\gradlew.bat clean build
```

Можно запустить `BUILD.cmd`. Готовый мод появится в `build/libs/moonotes-network-0.6.0.jar`. Используется Gradle Wrapper 9.6.0 и Fabric Loom 1.17.21; разрешение зависимостей требует доступа к репозиториям. Регрессионные проверки являются частью `build`; их не нужно отключать. На Windows проверка символической ссылки пропускается, если ОС запрещает её создание без дополнительных прав.

## Проверка этой версии

Код скомпилирован Java 25 против настоящих библиотек Minecraft 26.3 и Fabric, а готовый JAR упакован из этих классов. Проверены сетевые ограничения, кеш, каталог, ввод, геометрия интерфейса и состояния групп. Mixin annotation processor проверяет цели и дескрипторы против оригинального Streamotes. Сведения о проверке и хеши первого релиза находятся в [docs/VERIFICATION.md](../docs/VERIFICATION.md).

Проблемный эмот и эмот со старым ID реально скачаны новым Java-клиентом и функцией нового Worker. Полученные байты совпали. Worker проверен локальными тестами без записи пользовательского R2.

Ограничения проверки: графическое окно Minecraft здесь не запускалось. Полный запуск Gradle/Loom в рабочей среде блокируется ограничением системного сокета; готовый JAR собран настоящим JDK с библиотеками издателей, без заглушек API. Worker подготовлен, но не развёрнут в аккаунт владельца.

## Что проверить после установки

1. После обновления Worker нажми «Добрать отсутствующие» у второго каталога: должен появиться рост числа новых файлов. Сначала можно найти и проверить `TEATIMEMEGAZOOMAAAAAA`.
2. Создай группу, выбери пару эмотов, переименуй её и вернись к поиску. Убедись, что сообщение в чате не отправлялось.
3. Наведи отдельно на звезду и `⋯`: подсветка и подсказки должны различаться.
4. При обновлении списка Streamotes проверь, что его сообщение входит в общую очередь, а выбор «Отдельно» возвращает обычное поведение.
5. Проверь боковые разделы настроек и новые поля на своём масштабе GUI.
