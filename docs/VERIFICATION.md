# Проверка версии 0.5.3

Дата: **23 ноября 2026**.

## Подтверждено локально

- Network: 51 production Java-файл скомпилирован Java 25 против настоящих библиотек Minecraft 26.3, Fabric API 0.165.0+26.3 и Loader 0.20.1.
- Пройдены 29 программ регрессионных проверок Network: сеть, ограничения загрузки, кеш, каталоги, ввод, состояния групп, прокрутка и геометрия.
- Пройдены 30 тестов Worker.
- Пройдена проверка целей и дескрипторов Mixin против оригинального Streamotes 1.2.16+26.3.
- Пройдены 15 проверок реального API Streamotes, включая реестр и подготовку кадров анимации.
- Пройдены 9 проверок байткода Streamotes для точных вызовов автоматических уведомлений и сохранения исходных ветвей и логирования.
- Новый Java-клиент и функция нового Worker скачали проблемный эмот TEATIMEMEGAZOOMAAAAAA и эмот со старым ID. Байты и SHA-256 совпали.
- Готовый JAR сверён с исходниками и ресурсами; внутри нет исходных классов Streamotes или вложенного оригинального мода.
- Автор проекта подтвердил работу версии 0.5.3 в своём игровом клиенте.

## Ограничения

Графическое окно Minecraft не запускалось в среде подготовки кода. Полная сборка Gradle/Loom в той среде ограничена системным сокетом; готовый JAR получен настоящим JDK и библиотеками издателей, без заглушек API. Это не считается успешным прогоном Gradle на GitHub.

GitHub Actions настроен отдельно. До первого удалённого запуска его статус — **не проверен**. Сборки Actions используют обычный Gradle build и должны дать независимый результат для Windows и Linux.

Проверка нового Worker выполнялась без публикации в аккаунт Cloudflare. Подтверждение работы пользователя не сертифицирует доступность сервиса из каждой сети.
