# Moonotes Network 0.6.0-beta.5 — колесо и предпросмотр

**Основа:** `feature/0.6.0-beta4-ui-and-updater` · **Minecraft 26.3 · Fabric · Java 25**.

Стабильный `main` и beta.4 остаются неизменными. Это клиентская тестовая сборка. Для неё нужен основной `moonotes-0.4.1.jar` и оригинальный совместимый Streamotes.

## Изменения

1. **Центр колеса без повторов.** Без наведения: `Основные` и отдельный счётчик `1/2`. При наведении: `sad` и `Основные · 1/2`. Если страница одна, счётчик скрывается. Сообщения об ошибках и недоступные эмоты сохраняют приоритет.
2. **Кнопка настройки:** вместо символа `⚙` — `Настроить`. Верхние кнопки компактнее, переключение локального и глобального чата прежнее.
3. **Предпросмотр в редакторе:** задержка наведения 450 мс; появляется отдельная карточка с названием, каналом, крупной картинкой и статусом анимации. Используется существующий `EmotePreviews.drawDetailed` (асинхронная подготовка кадров и ограничение GPU-текстур), а не отдельный декодер. При смене эмота или фильтра освобождаются кадры предыдущего предпросмотра. Основная сетка остаётся статичной и не запускает анимации для всех эмотов.
4. **Положение карточки:** по возможности справа или слева от эмота, с ограничением по размерам экрана и резервом под нижние кнопки. В очень узком GUI допускается наложение на другие элементы списка, но панель «Сохранить / Отмена» остаётся доступной.

## Проверка

- Запустить Minecraft 26.3, открыть колесо `G`, проверить страницу с одним и с несколькими наборами; навести курсор на эмот и снять его.
- Открыть `Настроить`, навести курсор на обычный и анимированный эмоты, подождать до появления крупного предпросмотра.
- Проверить скорость анимации по сравнению с предпросмотром в основной библиотеке Moonotes. При отсутствии файла кадров должен оставаться статичный вариант.
- Прокрутить несколько страниц списка, выбрать эмот, сохранить, открыть колесо повторно.
- Открыть меню `⋯`, проверить его клики и отсутствие зависшего предпросмотра; проверить масштаб GUI, включая малые размеры.
- Убедиться, что камера и клавиши после выхода из колеса работают как в beta.4.

Автоматический регрессионный тест `WheelPreviewPolishCheck` проверяет логику подписи и границы всплывающей карточки для нескольких размеров экрана. **Успешный GitHub Actions CI не заменяет визуальный тест в игре.**

## Установка

Заменить только прежний `moonotes-network-*.jar` на **`moonotes-network-0.6.0-beta.5.jar`** из проверенного сборочного артефакта, оставив основной Moonotes, Streamotes и Fabric API. В папке `mods` не должно быть двух версий Moonotes Network одновременно.
