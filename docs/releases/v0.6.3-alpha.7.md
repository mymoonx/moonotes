# Moonotes 0.6.3-alpha.7 🌙

**Тестовая версия Moonotes для Minecraft Java 26.3 / Fabric.**  
Автор: **[mymoon_x](https://github.com/mymoonx)**.

Moonotes дополняет оригинальный Streamotes: эмоты 7TV, удобная библиотека, поиск и подсказки в чате, эффекты BTTV, а также отображение эмотов в книгах и на табличках.

> [!WARNING]
> **Alpha / предварительная версия.** Код и регрессионные тесты проходят проверки на Windows и Linux, но совместимость эффектов с реальными Paper-плагинами глобального чата ещё требует игрового теста. Стабильным релизом остаётся [Moonotes 0.6.0](https://github.com/mymoonx/moonotes/releases/tag/v0.6.0).

## ✨ Что нового в 0.6.3-alpha.7

- **Эффекты BTTV прямо в чате** (после префикса обязательно нужен пробел):
  - `w! WW` — растянуть эмот по ширине;
  - `h! WW` — отразить горизонтально;
  - `v! WW` — перевернуть вертикально;
  - `WW z! WW` — убрать видимый пробел перед следующим эмотом.
- **Односимвольные эмоты**: зарегистрированные короткие названия, например `w! q`, теперь распознаются, а после префикса доступны подсказки.
- **Подсветка префикса при вводе**: серый, пока подходящего эмота нет, голубой — когда он найден. Напечатанный текст и позиция курсора сохраняются.
- **Paper и глобальный чат**: поддержана обработка сообщений, разделённых сервером на разноцветные/кликабельные фрагменты. Формы `!w! q` и `! w! q` учитывают, что `!` может быть серверным префиксом глобального чата. Исходное отправляемое сообщение **не меняется**.
- **Устранена причина одной из задержек загрузки**: Streamotes больше не должен пытаться скачивать псевдоэмоты `w!`, `h!`, `v!`, `z!` как отдельные изображения. Это не гарантирует отсутствие сетевых задержек от других источников.

**Важно:** все BTTV-эффекты визуальные и выполняются локально. У игроков без совместимых модов текст может отображаться буквально. Изменения относятся к обычному чату и его строке ввода; BTTV-эффекты в книгах/табличках и командах пока не реализованы.

## 📦 Установка

**Потребуется:** Minecraft Java **26.3**, Java **25**, Fabric Loader **0.20.1+**, совместимый Fabric API и **оригинальный [Streamotes 1.2.16+26.3](https://modrinth.com/project/streamotes)**.

1. Закрой Minecraft.
2. Скачай из **Assets** внизу этой страницы **оба файла**:
   - `moonotes-0.4.3.jar` — основной Moonotes;
   - `moonotes-network-0.6.3-alpha.7.jar` — библиотека и сетевые функции.
3. Удали **старые JAR Moonotes и Moonotes Network** из папки `mods`, затем помести туда два скачанных файла. Оригинальный Streamotes и Fabric API **не удаляй**.
4. Запусти игру. Открой интерфейс командой `/moonotes` или через кнопку Moonotes в чате.

**При обновлении с alpha.6:** достаточно заменить Network JAR. Оставь `moonotes-0.4.3.jar` и оригинальный Streamotes. Не устанавливай несколько версий Network одновременно. Кеш, избранное и настройки удалять не нужно. Cloudflare Worker переустанавливать не требуется.

Файл `SHA256SUMS.txt` содержит контрольные суммы двух собранных JAR.

## 🧪 Что проверить на сервере

Напиши по очереди `w! q`, `!w! q`, `! w! q`, `h! WW`, `!WW` и обычное сообщение. Проверь, сохраняется ли серверная маршрутизация `!`, отображается ли картинка эмота и виден ли эффект. Если серверный плагин переписывает текст, работа модификаторов может отличаться.

Сообщить о проблеме можно в [GitHub Issues](https://github.com/mymoonx/moonotes/issues), приложив текст сообщения на экране, версии модов и диагностические счётчики BTTV. Перед загрузкой логов удали приватную информацию.
