# Moonotes Network 0.6.0-alpha.4 — анимация и интерфейс колеса

Экспериментальная клиентская сборка для Minecraft 26.3 / Fabric. Разработка продолжается в Draft PR #2; стабильная ветка и релиз 0.5.3 остаются отдельными.

## Установка

Замените старый `moonotes-network-*.jar` на `moonotes-network-0.6.0-alpha.4.jar` в папке `mods`. Оставьте Moonotes 0.4.1, оригинальный Streamotes и Fabric API. Нужна Java 25. JAR одинаково подходит для Windows и Linux; название операционной системы у артефакта CI означает систему сборки.

Переключатели находятся в **/moonotes → Настройки → Эмоты+**. Ранее сохранённые значения сохраняются. Для нового профиля таблички, книги и имена предметов по умолчанию выключены.

## Колесо

Откройте колесо клавишей **G**; её можно переназначить в управлении Minecraft.

| Действие | Результат |
| --- | --- |
| ЛКМ по эмоту | Сразу отправить один эмот в выбранный чат |
| Shift + ЛКМ | Открыть черновик с эмотом без отправки |
| ПКМ | Показать свою локальную реакцию |
| «Чат: локальный / глобальный (!)» | Выбрать канал отправки |
| «Настроить» или ЛКМ по пустому слоту | Открыть редактор восьми слотов |

В локальном режиме отправляется `42`, в глобальном — `!42`. Если в Streamotes требуется формат с двоеточиями, сообщения будут `:42:` и `!:42:`. Префикс `!` относится к сообщению целиком. Shift+ЛКМ сохраняет текст черновика и применяет выбранный канал; черновик команды не переписывается. Между отправками действует задержка 600 мс.

В редакторе выберите слот сверху, найдите эмот и нажмите на его карточку в компактной сетке (до 3 колонок). Перетаскивайте широкий ползунок справа или прокручивайте список колёсиком мыши. Стрелки меняют порядок слотов; «Очистить» оставляет выбранную позицию пустой. Нажмите **«Сохранить»**, чтобы применить набор, или «Отмена» / Esc для отмены. Повторное назначение уже выбранного эмота меняет два слота местами.

Набор и канал сохраняются в `config/moonotes-wheel.json`. Избранное и недавние эмоты используются только для первоначального заполнения и явного сброса. Выключение каталога временно освобождает его позиции, не сдвигая остальные.

Подсвечивается только сектор кольца. **Название выбранного эмота теперь внутри центра колеса** вместо надписи Moonotes, в несколько строк. Подсказки ЛКМ/ПКМ/Shift/Esc подняты сразу под кольцо на контрастную подложку. Верхние кнопки чата и настройки остаются на месте. Геометрия проверена для обычных размеров GUI от 320×240.

## Реакции

Реакция над персонажем проецируется как изображение размером **0,5 блока**. С расстоянием она уменьшается. Дальность до 32 блоков считается от камеры, включая вид от третьего лица и отдалённую камеру. Лучи от камеры к голове и изображению скрывают реакцию за препятствием. Непрозрачной рамки и квадратной подложки нет.

В первом лице собственная реакция показывается небольшим превью слева сверху с подписью «Ваша реакция». Длительность выбирается в настройках: 2, 4 или 6 секунд.

**ПКМ показывает реакцию только на вашем клиенте.** Для других клиентов нет отдельной сетевой отправки реакций. При получении обычного сообщения с эмотом Moonotes использует UUID отправителя из пакета чата и может показать эмот над этим игроком локально. Для сообщений, которые серверный плагин превращает в системный текст, предусмотрен только строгий запасной формат `<Ник> эмот`. Произвольное оформление такого системного чата ещё требует отдельного примера. Префиксы `!42` и `!:42:` распознаются.

## Таблички

Вместо оформления через эмот-глифы Streamotes применяется отдельный рендерер изображений на поверхности таблички. Он использует трансформацию её лицевой стороны, полную текстуру и координаты UV от 0 до 1. Общий обработчик покрывает обычные и подвесные таблички, обе стороны и настенное размещение.

Имена распознаются точно по активным каталогам Moonotes: например, `42`, `67`, `:42:`. До готовности изображения остаётся обычное имя. Отсутствующий в кеше используемый эмот запрашивается через существующий загрузчик Streamotes с ограничением частоты; просмотра галереи это не касается. Обычный текст сохраняет стили и цвет красителя, изображение не окрашивается этим цветом. Данные таблички на сервере не меняются.

## Книги, кафедры и редактор

Поддержаны просмотр книги, кафедра и экран **редактирования книги с пером**, показанный в игровом отчёте. Изображение рисуется поверх места, отведённого исходному имени; ширина текста и переносы остаются ванильными. Сохраняется строка `42`, а не специальный символ или ссылка.

Курсор, выделение, копирование и редактирование работают с исходным текстом. Когда курсор находится внутри имени, разделённые части остаются буквами, чтобы можно было исправить имя. Части длинного слова, оказавшиеся на другой строке, не распознаются как самостоятельные эмоты. Интерактивные ссылки готовой книги сохраняют внешний вид и область нажатия. Для строк, визуально переставленных двунаправленным письмом и не сопоставившихся с исходным текстом, остаётся обычная отрисовка.

## Ограничения и проверка

Изображения на табличках и в книгах **анимируются**, когда в общем кеше Streamotes присутствует корректный файл таймингов спрайт-листа. Подготовка кадров идёт в фоне, а кадры переключаются без изменений сохранённого текста. Пока анимация готовится, показывается первый кадр. Для защиты FPS и памяти ограничены число одновременно подготовленных анимаций (8), кадры (до 256 на эмот), размер подготовленных данных и число GPU-текстур. Анимации выше лимита и повреждённые тайминги отображаются статично. **Картинки в колесе и реакции пока статичны.** Имена предметов пока используют прежний экспериментальный способ оформления через Streamotes.

Проверены компиляция с настоящими Minecraft 26.3 / Fabric API и Java 25, регрессионные проверки геометрии, сохранения слотов, префикса чата и границ текста. Дополнительно реальный загрузчик Fabric Knot вместе со Streamotes 1.2.16+26.3 применил все четыре новых/переработанных обработчика Minecraft для табличек и книг. Эта проверка не запускает графику и не подтверждает внешний вид в игре.

Для повторного игрового теста:

1. Включите таблички и книги в «Эмоты+». На табличке напишите `42` и `67`, проверьте обе стороны и расстояние; в книге с пером — `42`, обычный текст рядом и перемещение курсора внутрь имени.
2. В G → «Настроить» назначьте свои восемь эмотов, сохраните и повторно откройте колесо. Проверьте название, подсказки и отсутствие второй рамки.
3. По очереди выберите локальный и глобальный чат. ЛКМ должен отправлять `42` и `!42`; Shift+ЛКМ должен открывать черновик.
4. В третьем лице отдалите камеру: реакция должна уменьшаться вместе с персонажем. Между камерой и персонажем поставьте препятствие — реакция должна исчезнуть.

Каталоги, избранное, группы и кеш эмотов сохраняются. Старые файлы отменённой экспериментальной Twitch-привязки очищаются прежним ограниченным механизмом; аккаунт Twitch для этих функций не нужен.
