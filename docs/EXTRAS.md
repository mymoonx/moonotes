# Moonotes 0.6.0-alpha.1 — игровые эмоты и реакции

> Экспериментальная клиентская версия. **Публичный релиз 0.5.3 не изменён.** От Twitch-привязки и Chatterino+ PLUS-пейнтов отказались; в этой ветке их нет.

## Новое

**Колесо эмотов (G).** Откройте в мире клавишей **G** (можно переназначить в «Управление → Назначение клавиш → Moonotes»). До восьми доступных эмотов берутся сначала из избранного, затем из недавно использованных, затем из выбранных подключённых каталогов. В каждом слоте показана миниатюра из локального кеша.

- **Левая кнопка мыши:** вставить название выбранного эмота в **черновик** чата. Сообщение не отправляется автоматически.
- **Правая кнопка мыши:** показать короткую реакцию **над своим персонажем**. Она локальная: другие игроки без дополнительного серверного механизма её не увидят. В режиме от первого лица собственный персонаж не отображается; для проверки переключитесь на вид от третьего лица.

**Игровые тексты.** В **Настройки → Эмоты+** находятся независимые переключатели для эмотов на табличках, в книгах/кафедрах и в названиях предметов. По умолчанию все выключены. Эти опции используют локальный способ оформления текста Streamotes и работают только для распознанных зарегистрированных имён эмотов. Меняются **только визуальные компоненты на клиенте**, а не содержимое табличек, книги или предмета на сервере.

**Настройки реакций.** Реакции можно отключить; длительность выбирается из 2, 4 или 6 секунд (по умолчанию 4). Реакция запускается только явным действием игрока в колесе, не при каждом сообщении.

## Важные ограничения

- Требуются оригинальный **Streamotes**, **Moonotes 0.4.1** и **Moonotes Network 0.6.0-alpha.1**, Fabric API, Minecraft 26.3 и Java 25. Старый Network JAR необходимо заменить.
- Реакция над головой выводится в виде временной строки-метки; отображение анимированного эмота как отдельной 3D-картинки ещё не реализовано.
- Если другой игрок поблизости пишет эмот в стандартном формате чата `<Ник> KEKW`, Moonotes пытается показать реакцию над ним. Это только локальный визуальный эффект: **он не подтверждает личность отправителя** и не предоставляет никаких игровых полномочий. Необычное оформление чата сервера может не распознаваться.
- Клиентский Streamotes должен распознать маркеры глифов в конкретном рендерере (табличка, книга, название). Возможность зависит от версии Streamotes. Нужен живой тест всех трёх поверхностей; успешная компиляция не гарантирует работу Mixin-хуков в игровом окне.
- Сложно стилизованные, интерактивные или составные текстовые компоненты не изменяются. Встроенное форматирование исходного текста остаётся приоритетом.
- Никаких серверных плагинов, автосообщений и новых внешних API в этой версии нет. **Twitch-аккаунт не требуется**.
- При первом запуске новой версии удаляются старые файлы экспериментальной Twitch-привязки и пейнтов (`config/moonotes-twitch-link.json`, `moonotes-paint*.json`, `moonotes-plus-paint-cache.json`). Каталоги, избранное, группы и кеш эмотов при этом **не удаляются**.

## Проверка

1. В игре откройте **/moonotes → Настройки → Эмоты+**, проверьте, что настройки сохраняются после перезапуска.
2. Добавьте несколько эмотов в избранное, нажмите **G**, кликните ЛКМ по эмоту и убедитесь, что открылся чат с неотправленным текстом.
3. Выберите другой эмот ПКМ, включите третий вид камерой (F5) и посмотрите на реакцию над собственным персонажем в течение 4 секунд. Попросите другого игрока с модом написать известный эмот в обычном чате и проверьте реакцию над его ником.
4. На табличке, в книге и в названии переименованного предмета напишите название **уже зарегистрированного Streamotes-эмота**. Включите соответствующий переключатель, сравните отображение с выключенным состоянием.
5. Проверьте, что обычный текст, серверные названия предметов и данные мира не изменяются, а FPS не падает при нескольких табличках рядом.
