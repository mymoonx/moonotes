# Moonotes 0.6.0-alpha.2 — игровые эмоты и реакции

> Экспериментальная клиентская версия. **Публичный релиз 0.5.3 не изменён.** От Twitch-привязки и Chatterino+ PLUS-пейнтов отказались; в этой ветке их нет.

## Новое

**Колесо эмотов (G).** Откройте в мире клавишей **G** (можно переназначить в «Управление → Назначение клавиш → Moonotes»). До восьми доступных эмотов берутся сначала из избранного, затем из недавно использованных, затем из выбранных подключённых каталогов. Теперь это **единое кольцо из восьми секторов**: в секторах только картинки; название выбранного эмота выводится отдельно под колесом.

- **Левая кнопка мыши:** **сразу отправить** один эмот в игровой чат (с ограничением повторных нажатий).
- **Shift + левая кнопка мыши:** вставить название эмота в черновик без отправки.
- **Правая кнопка мыши:** показать картинку-реакцию над своим персонажем. В первом лице собственная реакция видна возле центра экрана — можно проверить одному. Никакие серверные сообщения при ПКМ не отправляются.

**Игровые тексты.** В **Настройки → Эмоты+** находятся независимые переключатели для эмотов на табличках, в книгах/кафедрах и в названиях предметов. По умолчанию все выключены. Эти опции используют локальный способ оформления текста Streamotes и работают только для распознанных зарегистрированных имён эмотов. Меняются **только визуальные компоненты на клиенте**, а не содержимое табличек, книги или предмета на сервере.

**Настройки реакций.** Реакции можно отключить; длительность выбирается из 2, 4 или 6 секунд (по умолчанию 4). Реакция запускается только явным действием игрока в колесе, не при каждом сообщении.

## Важные ограничения

- Требуются оригинальный **Streamotes**, **Moonotes 0.4.1** и **Moonotes Network 0.6.0-alpha.2**, Fabric API, Minecraft 26.3 и Java 25. Старый Network JAR необходимо заменить.
- Реакция теперь показывает **изображение эмота из локального кеша** над видимой позицией персонажа через HUD; в первом лице собственная реакция отображается возле прицела. Это пока статичная миниатюра, не полноценный 3D-спрайт с анимацией.
- Если другой игрок поблизости пишет эмот в стандартном формате чата `<Ник> KEKW`, Moonotes пытается показать реакцию над ним. Это только локальный визуальный эффект: **он не подтверждает личность отправителя** и не предоставляет никаких игровых полномочий. Необычное оформление чата сервера может не распознаваться.
- **Таблички:** после первого теста обнаружено повреждённое отображение 3D-глифов. В этой версии добавлена проверка готовности текстуры и белый цвет самого эмота, но **исправление ещё не проверено в игре**. Если остаются чёрные точки, отключите «Эмоты на табличках»: потребуется отдельный рендерер, не только текстовый Mixin.
- **Книги:** оформление доступно при **просмотре готовой книги**. Экран **редактирования книги** Minecraft использует отдельное текстовое поле; живое отображение эмотов в нём **пока не поддерживается**, чтобы не ломать курсор, перенос строк и сохранение страниц.
- **Предметы:** только локальное отображение имён. Для всех поверхностей нужна проверка в игре: компиляция не гарантирует корректного графического рендера.
- Сложно стилизованные, интерактивные или составные текстовые компоненты не изменяются. Встроенное форматирование исходного текста остаётся приоритетом.
- Никаких серверных плагинов, автосообщений и новых внешних API в этой версии нет. **Twitch-аккаунт не требуется**.
- При первом запуске новой версии удаляются старые файлы экспериментальной Twitch-привязки и пейнтов (`config/moonotes-twitch-link.json`, `moonotes-paint*.json`, `moonotes-plus-paint-cache.json`). Каталоги, избранное, группы и кеш эмотов при этом **не удаляются**.

## Проверка

1. В игре откройте **/moonotes → Настройки → Эмоты+**, проверьте, что настройки сохраняются после перезапуска.
2. Добавьте несколько эмотов в избранное, нажмите **G**, кликните ЛКМ — должен отправиться один эмот в чат. Затем **Shift + ЛКМ** — должен открыться неотправленный черновик.
3. Выберите другой эмот ПКМ: в первом лице изображение должно появиться возле прицела, а в третьем — над персонажем. Срок по умолчанию 4 секунды. Если есть второй игрок, проверьте реакцию на его эмот в стандартном чате.
4. Напишите **точное название уже зарегистрированного Streamotes-эмота** на табличке, в **готовой книге** и в названии переименованного предмета. Включите нужные переключатели, дождитесь загрузки картинки и сравните с выключенным состоянием. Не используйте редактор книги как тест просмотра.
5. Проверьте, что обычный текст, серверные названия предметов и данные мира не изменяются, а FPS не падает при нескольких табличках рядом.
