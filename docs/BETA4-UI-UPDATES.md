# Moonotes Network 0.6.0-beta.4 — полировка интерфейса и безопасные обновления

**Minecraft Java 26.3 · Fabric Loader 0.20.1+ · Fabric API · Streamotes 1.2.16+26.3 · Java 25**

Это тестовая сборка, основанная на работающей 0.6.0-beta.3. **Стабильная версия v0.5.3 и публичный alpha.4 не заменяются.**

## Установка для тестирования

1. Закройте Minecraft.
2. Оставьте `moonotes-0.4.1.jar`, оригинальный Streamotes и совместимый Fabric API.
3. Удалите старый `moonotes-network-0.6.0-beta.3.jar`; в папке `mods` должен оставаться **один** JAR `moonotes-network`.
4. Установите `moonotes-network-0.6.0-beta.4.jar`. Настройки, группы, страницы колеса и кеш переносить не нужно.
5. Проверьте обычное управление камерой и клавиши в своём мире — защита от неназначенных SDL-клавиш сохранена.

## Интерфейс: что изменилось

### Колесо эмотов

- Верхняя панель показывает **только канал чата и «⚙ Настроить»**. Стрелки переключения страниц и дублирующиеся номера убраны.
- Когда страниц больше одной, в центре кольца под названием выбранного эмота отображаются **имя страницы и номер**. При единственной странице индикатор скрыт.
- Листайте страницы **колёсиком мыши над кольцом**. Переключение больше не пересоздаёт сам экран и текстуры.
- ЛКМ отправляет эмот, ПКМ показывает локальную реакцию, Shift+ЛКМ готовит текст сообщения — как в beta.3.

### Редактор

- Отдельная компактная кнопка выбранной страницы открывает список страниц или позволяет добавить новую.
- В меню `⋯` находятся переименование, привязка/отвязка группы, удаление и очистка слота, автозаполнение и перемещение слота. Мелкие действия больше не занимают всю нижнюю часть экрана.
- Внизу остаются основные действия «Отмена» и «Сохранить».
- При редактировании связанной страницы состав берётся из той же мини-библиотеки и напрямую не перезаписывается.
- Черновые изменения ручных слотов сохраняются только после явного нажатия «Сохранить».

### Мини-библиотека

- Окно автоматически уменьшается для коротких списков (например, для единственной группы).
- `×` имеет нормальный размер 20×20 и выровнен по строке заголовка.
- Нижняя кнопка создания группы получила отступ **8 px снизу**.
- Постоянное пустое поле справа убрано: место под скроллбар выделяется только при необходимости.
- Поиск, действия с группами, избранное и вставка в чат сохранены.

### Кнопки и настройки

- В редакторе положения кнопок можно **связать две кнопки и перетаскивать их вместе**. Появились направляющие выравнивания.
- Префикс глобального чата больше не занимает верхнюю часть редактора кнопок. Он теперь в **Настройки → Чат → Глобальный чат**.
- Раздел поддержки разбит на вкладки **Проверка, Качество, Данные, Обновления**.
- «Анонимная телеметрия» в интерфейсе теперь называется **«Локальная статистика»** — это точнее описывает работу.

## Проверка обновлений и установка

В `/moonotes → Настройки → Дополнительно → Диагностика и поддержка → Обновления`:

**Каналы**
- **Стабильные** — только обычные GitHub Releases (по умолчанию).
- **Stable + Beta** — стабильные версии и предварительные релизы. Пользователь выбирает канал вручную.

**Режимы**
- **Выключено** — вообще нет автоматических проверок.
- **Уведомлять** — проверка не чаще раза в сутки, после входа в мир; в игре показывается уведомление.
- **Скачивать** — в дополнение к уведомлению автоматически загружается и проверяется новый сетевой JAR.
- **Устанавливать при выходе** — только после явного выбора этого режима: проверенный новый JAR планируется к замене после завершения Minecraft, с резервной копией старого.

**Ручные действия** — «Проверить обновления», «Скачать проверенный JAR», «Установить после выхода», «Откатить обновление», «Отменить запланированную установку».

**Защита:**
- Источник ограничен официальными `github.com/mymoonx/moonotes` Releases. Нельзя подставить произвольную ссылку из ответа API.
- Для каждого обновления **обязательно наличие `SHA256SUMS.txt`** с верной суммой конкретного JAR. Если файла/суммы нет, обновление не предлагается для автоустановки.
- После скачивания дополнительно проверяются `fabric.mod.json`, ID `moonotes_network`, точный номер версии и Minecraft 26.3.
- Замена происходит **только после закрытия игры** отдельным процессом Java. Старый JAR сохраняется в `config/moonotes-updates`; откат также выполняется после выхода.
- При ошибке установки механизм пытается вернуть старый JAR. В папке `mods` запрещены одновременно два `moonotes-network` JAR.
- **Это обновляет только Moonotes Network.** Основной `moonotes-0.4.1.jar` остаётся отдельно: если будущий релиз потребует новую основную часть, её обновление пока нужно выполнять вручную.
- Для запуска обновления у пользователя должна быть обычная установка с JAR-файлом в папке `mods`. Нестандартные файловые конфигурации лаунчера требуют ручной установки.

**Скачивание через Modrinth/Prism** можно будет подключить как дополнительный канал после публикации совместимых модов и налаживания выпусков; в этой версии **Modrinth-проект ещё не опубликован**.

## Приватность

Техническая самодиагностика, резервные копии и локальная статистика не отправляются на сервер без действий игрока. GitHub получает обычный HTTPS-запрос только при проверке обновлений, как любой сервис скачивания; отдельный сбор телеметрии по-прежнему **не развёрнут**. Полные логи и токены автоматически не прикладываются.

## Ручная проверка перед стабильным 0.6.0

1. Мир открывается, камера вращается, чат и бинды работают.
2. Проверить колесо с одной и несколькими страницами, переключение колёсиком и центр кольца.
3. Проверить меню `⋯`, добавление/переименование/удаление страниц и редактирование слотов.
4. Проверить синхронизацию нескольких страниц с группой из более восьми эмотов.
5. Открыть мини-библиотеку с 0, 1, 5 и 20 эмотами при разных масштабах GUI.
6. Переместить обе кнопки чата, сохранить, перезапустить, затем попробовать совместное перетаскивание.
7. Проверить вкладки поддержки и что нет незапрошенных отправок отчётов.
8. Переключить Stable/Beta и вручную запросить новые версии.
9. На тестовой копии Minecraft проверить автоустановку и откат после выхода. Проверка JAR в реальном Prism Launcher необходима сверх зелёного GitHub Actions CI.
