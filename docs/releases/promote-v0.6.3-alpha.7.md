# Moonotes 0.6.3-alpha.7 — выбрать как Latest

Релиз: https://github.com/mymoonx/moonotes/releases/tag/v0.6.3-alpha.7

По запросу владельца проекта перенести зелёную метку **Latest** в боковом блоке Releases GitHub с 0.6.0 на 0.6.3-alpha.7.

Этот релиз всё ещё тестовый: слово `alpha` остаётся в номере версии, заголовке и примечаниях, где сохраняется предупреждение о непроверенной совместимости с некоторыми Paper-плагинами. Для метки Latest GitHub требует снять служебный статус prerelease.

Существующие файлы `.jar`, теги и хеш-суммы не заменяются. Старая 0.6.0 остаётся доступной.

Публикация запускается отдельным GitHub Actions workflow `promote-alpha7-latest.yml` на основной ветке.
