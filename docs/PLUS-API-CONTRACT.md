# Chatterino+ PLUS — контракт для интеграции Moonotes

**Статус: официальное подключение пока заблокировано отсутствием подтверждённого контракта API.**

Moonotes — независимый клиентский мод Minecraft. Цель — показать **именно Chatterino+ PLUS-пейнт, назначенный подтверждённому Twitch ID**; пейнты 7TV и демонстрационный градиент не должны подменять PLUS.

## Что подтверждено

- [Правила Chatterino+](https://chat.eblo.id/chatterino): разрешено использовать официальный функционал через предоставляемый API; подключение сторонних клиентов в обход предоставленного API запрещено.
- [Политика расширения](https://chat.eblo.id/chatterino/privacy): Chatterino+ распространяет публичные списки PLUS-пейнтов и значков.
- [Поддержка Chatterino+](https://chat.eblo.id/chatterino/support): контакт для запроса документации — chatterinoplus@gmail.com, Telegram t.me/rish098.
- В Moonotes уже есть подтверждённый Twitch ID, но **OAuth-токен Twitch не сохраняется**. Нельзя заменять его доступом к закрытым API PLUS.

## Что необходимо уточнить у владельца Chatterino+

1. Документированный URL и HTTP-метод получения **публичных PLUS-пейнтов**, желательно поиск по Twitch ID.
2. Формат ответа для назначений, слоёв, цветов, stop positions, rotation, времени анимации, изображений, кадров и badge.
3. Допустимо ли обращаться из независимого открытого Minecraft-мода, а не только с сайта, расширения и официального Chatterino+.
4. Разрешённый User-Agent, лимиты запросов, кеширование, ETag/Last-Modified, срок жизни данных и обработка 429.
5. Правила повторной отрисовки ассетов и ссылки на изображения/анимированные WebP.
6. Нужна ли отдельная идентификация приложения; **никогда не присылать Client Secret или пользовательские OAuth-токены**.

## Что уже готово в экспериментальной ветке

- Локальная Twitch-привязка по UUID Minecraft и токенобезопасный Device Code.
- Настройки: включение, чат, TAB, демонстрационная анимация и импорт **локального** градиента.
- Контрольный механизм `PlusPaintCache` для одного Twitch ID: 64 КиБ на описание, 6 часов свежести, до 24 часов офлайн-кеша, атомарная запись.
- Проверка идентификатора при чтении кеша; при отвязке Twitch кеш удаляется.
- Сохранение исходных эмотов и существующего Streamotes без изменений.

**Важно:** `PlusPaintCache.acceptFromOfficialApi` — только внутренняя точка подключения для будущего разрешённого адаптера. В текущем коде никто не вызывает этот метод: он не доказывает, что PLUS API уже используется.

## Что будет после подтверждения API

Сначала реализовать авторизованный read-only адаптер, верификацию схемы, ограничение запросов и тесты с фикстурами ответов. Затем — точную отрисовку поддерживаемых PLUS-слоёв, изображения и WebP, качественную анимацию с контролем нагрузки; отдельные визуальные хуки чата, TAB и имён над головой — только после проверки совместимости с Minecraft 26.3.

До этого любые картинки или градиенты в настройках имеют статус **локальный демонстрационный или импортированный пейнт**, а не подтверждённый Chatterino+ PLUS.
